# Implementación de UI

1. Leer `AGENTS.md` y `docs/DESIGN_SYSTEM.md`.
2. Revisar el mockup de Figma o el diseño que aporte el equipo.
3. Trabajar en `frontend/templates/`, `frontend/static/` y rutas acordadas.
4. Reusar `base.html`, `components/ui.html` y tokens CSS; evitar duplicar componentes.
5. Usar iconos SVG de la misma familia, con texto para acciones importantes.
6. Verificar móvil (390 px) y escritorio, foco, contraste y estados vacío/error.
7. Ejecutar los checks y reportar cómo comprobar la pantalla.
