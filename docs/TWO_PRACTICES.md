# Dos ensayos: cómo utilizar el mismo repo

No vienen ejercicios ni funcionalidades educativas predefinidas. La base sirve para ambos ensayos.

## Ensayo 1 — Técnica

- Arrancar el proyecto en las 3 computadoras.
- Cada integrante abre un PR pequeño con revisión manual por otra persona.
- Confirmar que una página Jinja2 y una ruta FastAPI funcionan.
- Comprobar Vercel `/health` y, si configuran Neon, `/health/db`.

## Ensayo 2 — Flujo de MVP

- Definir en grupo un problema educativo pequeño.
- Escribir 2 historias de usuario con criterios de aceptación.
- Dibujar un único flujo en Figma.
- Reemplazar la demo genérica por una función completa y comprobar manualmente sus casos principales y errores.
- Presentar el flujo con una URL pública y 1 captura de respaldo.

Los ejemplos son de preparación. Confirmar los requisitos del evento sobre trabajo previo y uso de IA.
