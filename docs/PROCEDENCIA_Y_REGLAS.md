# Procedencia y uso del starter

**Importante:** antes de usar este paquete en la competición, confirmar que las reglas de Abstracthon autorizan reutilizar código anterior. Crear un repositorio nuevo NO significa que el código sea nuevo. Si la organización exige desarrollar todo desde cero, usar este repositorio solamente como referencia y no copiarlo.

- Base técnica adaptada del repositorio de ensayos: https://github.com/aleVas1704/abstracthon-edu
- Incluye estructura FastAPI, Jinja2 y estilos reutilizables preparados anteriormente.
- Incluye la identidad visual NeoQuest, SVG Lucide con su licencia y SVG originales del kit, además del tema NeoQuest Mentor.
- Las funcionalidades de aplicación, flujos, nombres de botones, rutas de negocio y pantallas finales NO se definen aquí; el equipo los determinará en los mockups e implementación.
- No se copian branches de colaboradores ni código que no esté en el starter original.
- Conservar este documento en el repositorio final para distinguir material reutilizado de los desarrollos realizados durante la hackathon.
