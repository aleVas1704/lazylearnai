# Design System UI — versión mínima

- Tipografía: sistema (`system-ui`) y texto base de 16 px.
- Paleta propuesta: fondo `#f8fafc`, superficie `#ffffff`, texto `#172033`, principal `#1d4ed8`.
- Espaciado: 4/8/12/16/24/32 px; bordes de 8 px botones y 12 px tarjetas.
- Componentes reutilizables: badge, botones, tarjetas y estados de resultado en `components/ui.html`.
- CSS: `tokens.css`, `base.css`, `components.css`, `layout.css`.
- Iconos: SVG de Lucide en `frontend/static/icons/` según necesidad.
- Responsive: móvil (390px), tablet (768px) y escritorio (1440px).
- Figma: Foundations, Components, Desktop, Mobile, Prototype.

El objetivo es consistencia visual, no crear un paquete de componentes complejo antes de conocer el reto.
